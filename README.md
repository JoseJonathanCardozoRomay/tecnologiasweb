# Sistema de Gestión de Tutorías Académicas

Sistema web para la administración, programación y seguimiento de tutorías académicas. Permite conectar a estudiantes con tutores para la reserva de sesiones y ofrece un panel de administración para el control global.

---

## Requisitos del Sistema

- **Git** (v2.x o superior)
- **Docker Desktop** (v20.10 o superior)
- **Docker Compose**
- **Navegador Web** (Google Chrome, Mozilla Firefox o Microsoft Edge)
